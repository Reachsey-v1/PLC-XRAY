# GUI User Guide

1. Start `PLC-XRAY-GUI.pyw` on Windows with Python 3.10+ or use the packaged EXE from GitHub Actions.
2. Click **Open Project** and select a `.gxw`.
3. Review SHA-256, stream count, POU count, labels and devices.
4. Review diagnostics/evidence status.
5. Export JSON if required.

All operations are read-only. Native GX Works compile/open and online PLC tests must be performed separately.
